# AEH Examples

Start with the repository [README](../README.md) and
[current status](../docs/status.md). Use a disposable repository for the first
bootstrap. The current source is `0.3.0.dev0`; the latest public release is
`v0.2.0`, and PyPI is not published.

- minimal/ — smallest possible bootstrap + first change walkthrough (Python).
- generic-business/ — same five-level workflow on a neutral business fixture
  (order submission), including LIGHTWEIGHT/STANDARD/CRITICAL/EXPLORE pilots.

Both were executed by the V0.1 release gate; see docs/pilots/ for the records.

Production certification: these examples are examples, not production-certified
integrations. No Unity, .NET, or general brownfield production claim is made.
